# Team progress files

Drop progress exports here (Team tab → "Export my progress") and list each
filename in `manifest.json`:

    { "files": ["sam.json", "alex.json", "jordan.json"] }

When the app is served from the repo (locally or via GitHub Pages), the Team
tab loads these automatically — leaderboard and unit-coverage comparison with
zero servers. Re-export and re-commit after each practice week.
